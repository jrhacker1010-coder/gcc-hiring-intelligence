# AI-Powered GCC Hiring Intelligence Platform

## Problem
Global Capability Centers face manual, fragmented hiring processes causing delays, bias, and candidate drop-offs.

## Solution
An AI-driven hiring intelligence platform that automates resume screening, interview decisions, and engagement risk prediction.

## Key Features
- Resume–JD AI Matching
- Interview Decision Intelligence
- Candidate Drop-Off Risk Detection
- Hiring Assistant Chatbot
- Live Interactive Dashboard

## Tech Stack
- Python
- Streamlit
- scikit-learn
- NLP (TF-IDF)
- Streamlit Community Cloud
